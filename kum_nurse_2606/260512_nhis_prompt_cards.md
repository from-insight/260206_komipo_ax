# 공단 리더 AI 실습 프롬프트 카드

> **사용법**: 이 카드를 보면서 휴대폰 앱(뤼튼 / 클로바X)에 입력해보세요.  
> **주의**: 실명·주민번호·개인정보는 절대 입력하지 않습니다.

---

## 🃏 카드 A — 지역 현안 브리핑 Agent

### 기본형 (2라운드)

```
당신은 국민건강보험공단 ○○지사장입니다.

다음 4종 자료를 보고
[이번 주 위험 이슈 Top 5]를 정리해주세요.

형식:
번호. 이슈명
- 위험도: 상/중/하
- 핵심 내용: (2줄)
- 권고 조치: (1줄)

[민원 데이터] (여기에 입력)
[언론 보도]   (여기에 입력)
[운영 지표]   (여기에 입력)
[현장 보고]   (여기에 입력)
```

---

### 심화형 CoT (3라운드)

```
당신은 국민건강보험공단 ○○지사장입니다.

다음 자료에서 [이번 주 위험 이슈 Top 5]를
단계별로 분석해주세요.

[1단계] 모든 이슈 추출 (10개 이상)
[2단계] 영향도 평가 (피해 규모·대상 수)
[3단계] 시급성 평가 (방치 시 결과)
[4단계] 영향도 × 시급성 → Top 5 선정
[5단계] 이슈별 권고 조치
        - 이번 주 / 다음 주 / 한 달 내

마지막: Top 5 한 장 요약 (표 형식)

[자료 붙여넣기]
```

## 🃏 카드 B — 지사 편차 분석 Agent

### 기본형 (2라운드)

```
당신은 지역본부 분석 담당자입니다.

다음 5개 지사 데이터에서:

1. 평균 대비 이탈한 이상치 지사를 찾아주세요
   (어떤 지표에서, 평균 대비 얼마나)

2. 우수/부진 지사를 구분하고 특징을 정리해주세요

3. 부진 지사의 가능한 원인 가설 3가지를
   참고 정보를 활용해 제시해주세요

[데이터 표 붙여넣기]
[참고 정보 붙여넣기]
```

---

### 심화형 — 액션 도출 (3라운드)

```
앞선 분석을 바탕으로:

[1] 즉시 개입 필요 지사
    - 무엇을 / 누가 / 언제까지

[2] 모범사례 공유 대상 지사
    - 어떤 노하우를 / 어떻게 전파

[3] 다음 분기 KPI에 추가할 지표 (최대 3개)

[4] 분기별 정기 편차 분석 운영 방안
    - 주기 / 주관 / 보고 대상

표 형식으로, 실행 가능성과 우선순위 함께 표기
```

## 🃏 카드 C — 민원 답변 초안

```
당신은 국민건강보험공단 민원 담당자입니다.

다음 민원에 대한 정중한 답변 초안을 작성해주세요.

[민원 내용]
(여기에 민원 내용 입력 — 실명·개인정보 제외)

조건:
- 200자 이내
- 공감 표현으로 시작
- 핵심 안내 3단계로 정리
- 추가 문의 안내로 마무리
- 공식적이되 이해하기 쉬운 어조
```

---

## 🃏 카드 D — 회의록 요약 + 액션 추출

```
다음 회의 내용을 정리해주세요.

[회의 내용]
(여기에 회의 기록 붙여넣기)

형식:
1. 회의 요약 (3줄 이내)
2. 핵심 문제점 (번호 목록)
3. 액션 아이템
   | 담당자 | 내용 | 기한 |
4. 다음 회의 확인 사항
```

## 🃏 카드 E — 프롬프트 수정 체크리스트

결과가 마음에 안 들 때 이 순서로 점검하세요.

| 체크 | 항목 | 수정 방법 |
|---|---|---|
| □ | 역할 지정했나? | "당신은 ○○입니다" 추가 |
| □ | 지시가 구체적인가? | "무엇을, 어떻게" 명시 |
| □ | 자료를 넣었나? | [대괄호]에 내용 입력 |
| □ | 형식을 지정했나? | 표/목록/글자수 명시 |
| □ | 너무 많이 시키진 않나? | 한 번에 1~2가지만 |
| □ | 부정문 쓰진 않나? | "~하지 마" → "~해줘"로 변경 |
| □ | CoT 추가할까? | "단계별로 생각해주세요" 추가 |

---

> **기억하세요**  
> AI는 첫 번째 답이 완벽하지 않아도 됩니다.  
> 2~3번 대화로 다듬는 것이 정상입니다.  
> "더 짧게", "표 형식으로", "근거 추가" — 이렇게 이어가세요.
