## 자주 나오는 질문 & 답변

**Q: "AI가 쓴 걸 제출해도 되나요?"**  
A: 공단 내부 지침 확인 필수. 일반적으로 AI 초안을 사람이 검토·수정한 결과물은 사용 가능. 직접 생성했다고 위장하는 것은 문제.

**Q: "어떤 AI가 제일 좋나요?"**  
A: 용도마다 다름. 한국어 업무: 클로바X·뤼튼. 긴 문서 분석: Claude. 검색 연동: Perplexity·Gemini.

**Q: "사내에 AI 도입하려면?"**  
A: IT부서·보안팀 협의 필요. 현재 공공기관 전용 안전한 AI 솔루션 많이 나오고 있음. 국가정보원 보안 가이드라인 참고.

**Q: "AI가 내 일자리 빼앗지 않나요?"**  
A: 반복 작업은 줄어들지만, 판단·소통·관리 역할은 더 중요해짐. 변화에 적응하는 사람이 오히려 기회 얻음.

**Q: "입력한 내용이 AI 학습에 쓰이나요?"**  
A: 서비스마다 다름. 뤼튼·클로바X 개인정보 처리방침 확인 필요. 민감 정보는 어떤 경우에도 입력 금지.
