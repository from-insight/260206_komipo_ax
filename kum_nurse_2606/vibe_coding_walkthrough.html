STEP 1

STEP 2

프롬프트를 다듬어 품질 고정하기

결과를 매번 일정하게 만들려면 세 가지를 넣습니다 — 역할(누구처럼), 규칙·형식(어떻게), 예시(이렇게). 이게 'few-shot'이고, 누가 써도 같은 결과가 나오게 합니다.

🗣️ 다듬은 프롬프트
너는 상급종합병원 진료협력센터 담당자야.
아래 [메모]를 정식 진료의뢰서로 변환해줘.

규칙:
- 항목 순서: 의뢰기관 / 환자정보 / 임상요약 / 의뢰사유

- 맨 끝에 권장 진료과와 긴급도(높음/중간/낮음)를 한 줄로

STEP 3

"이거 앱으로 만들어줘" — 바이브코딩

매번 메모를 붙여넣기 번거로우면, 챗봇에게 작은 웹앱으로 만들어 달라고 하면 됩니다. 코드를 몰라도 됩니다. "한 파일로, 외부 라이브러리 없이"라고만 덧붙이세요.

🗣️ 바이브코딩 프롬프트
위 작업을 매번 반복하기 번거로워.

입력칸(환자명, 나이/성별, 메모)과 '생성' 버튼이 있고,
버튼을 누르면 위 규칙대로 의뢰서를 만들어 보여주는
HTML 파일 하나로 만들어줘.
외부 라이브러리 없이, 복사해서 바로 열 수 있게.
🤖 AI가 만들어 준 미니앱 (실제로 동작합니다)
의뢰서 생성기 v1 · referral.html
💡 직접 입력을 바꿔서 눌러보세요. 이게 1차 버전입니다 — 일단 동작하면 충분합니다.
STEP 4

한 번에 하나씩 기능 추가하기

바이브코딩의 핵심은 대화로 조금씩 키우는 것입니다. 완벽한 설계 대신, 결과를 보고 "이것도 해줘"를 반복합니다.

🗣️ 추가 요청
좋아. 결과 위에 '권장 진료과'와 '긴급도'를
색깔 배지로 보여줘.
긴급도 '높음'은 빨간색으로 강조해줘.
🤖 업그레이드된 미니앱 (배지 추가됨)
의뢰서 생성기 v2 · 자동 분류 추가
💡 메모를 바꾸면 진료과·긴급도 배지가 자동으로 달라집니다. 이런 식으로 "원문 메모 표시", "PDF 저장", "회송서 양식" 등을 한 번에 하나씩 붙여가면 됩니다.
STEP 5

작은 예제를 실무로 키워나가기

여기까지가 "작은 단위에서 시작"의 전부입니다. 이제 필요에 따라 단계적으로 확장합니다. 위로 갈수록 강력하지만, 아래 1~2단계만으로도 실무 효과가 납니다.

오늘 당장
① 저장·공유
완성한 HTML을 팀에 공유하거나 프롬프트를 템플릿으로 저장해 표준화
반나절
② 데이터 채우기
실제 분류 목록(진료과 코드)·협력병원 목록을 넣어 현장 맞춤화
자동 실행
③ 반복 자동화
"매일 의뢰 건 모아 요약" 등을 예약·트리거로 연결, 결과만 확인
IT 협업
④ 시스템 연동
EMR·문서양식과 API로 연결해 입력→작성→저장까지 완전 자동화
⚠️ 실무 적용 전 필수: 실제 환자정보는 외부 공개 챗봇에 입력하지 마세요. 비식별화하거나 원내 폐쇄망·규정 준수 솔루션을 쓰고, 최종 검토·서명은 반드시 의료진이 합니다.
🧭 핵심만 기억하면
① 말로 시작 → ② 역할·예시로 다듬기 → ③ "앱으로 만들어줘" → ④ 하나씩 추가 → ⑤ 검증하며 확장. 완벽하게 설계하고 시작하는 게 아니라, 작게 만들어 돌려보고 대화로 키우는 것 — 그게 바이브코딩입니다.
시연용 따라하기 데모 · 미니앱의 AI 생성은 입력값을 규칙에 맞춰 조립하는 방식으로 동작을 재현합니다.
실제로는 같은 프롬프트를 생성형 AI에 주면 동일한 결과를 얻을 수 있습니다.
